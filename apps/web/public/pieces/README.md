# Piece artwork

Classic and Club are original SVG artwork in this application. Club is a rounded,
chess.com-inspired design, not an official chess.com piece set.

The unmodified SVG source files in `cburnett/` and `merida/` are from
https://github.com/lichess-org/lila/tree/master/public/piece (retrieved 2026-10-01).

- Cburnett: Colin M. L. Burnett, GPL version 2 or later.
- Merida: Armando Hernandez Marroquin, GPL version 2 or later.
